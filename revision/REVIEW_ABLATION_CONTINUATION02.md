# REVIEW-ABLATION-CONTINUATION02：声明 L/H 与曲率组件的配对消融

状态：2026-11-07，运行前冻结。机器参数见同目录 JSON。本轮只运行合成消融；真实实验维持准备阶段。

## 1. 本轮问题与已有证据

问题是：在同一批机制集合、观测和桥接路径上，过低、正确或保守的光滑性声明，分别怎样改变真实误差、可计算区间与发布成本？删除曲率项是否确实低估当前组合的因果偏差，还是被 Lipschitz 分支或采样保守性屏蔽？不要求负控制一定出现经验失败。

已读 AGENTS、全 12 项 review tracker、`ABLATION_AUDIT_20261107.md`、上一轮机制集合结果。已有完整配对的权重消融、Bbar/BLip/min 几何消融、联合校准和选择保护的局部对照；新矩阵定理的历史证据有限预算主实验也已完成。本轮不重复这些实验。

机制集合轮说明忽略集合半径会显著缩窄区间并改变发布成本，但其 proxy 负控制在该配置下覆盖率仍很高。因此不能据此宣称机制集合无用，也不能增噪、换种子或挑几何来制造失败。本轮保留原数据生成过程，只干预声明 L/H。

方法身份是原一般 U/L/H 模型的 simplex 权重与可计算 `min(Bbar, BLip)` 证书；它不是新矩阵矩定理、不是 sharp partial-identification region，也不是 legacy point estimator。本轮所有权重只使用设计信息，所有桥接顺序固定为共同随机排列。

## 2. 最小五组与公平配对

| 组 | 声明 L | 声明 H | 解释 |
|---|---:|---:|---|
| baseline | L | H | 正确的解析上界 |
| L_half | L/2 | H | 三个曲面都低于机制域所需梯度上确界，负控制 |
| L_double | 2L | H | 合法而保守的声明 |
| H_zero | L | 0 | 线性曲面等于 baseline；非线性曲面删除曲率项，Bbar 声明条件不成立 |
| H_double | L | 2H | 合法而保守；线性曲面仍与 baseline 相同 |

不做 L/H 二维网格，不增加 H/2，也不增加第六套 BLip-only 优化。已有几何消融覆盖独立优化 BLip；本轮同权重分解保留合法 BLip，足以区分“删除 H 的无效 Bbar”与“使用本来就无需 H 的合法 BLip”。

每世界共用原 calibrated_U 的中心、所有半径、校准分数、真实机制位置、源效应噪声、候选集合与随机桥接顺序。每组分别重新优化，warm start 仅使用本组上一预算的权重；同时冻结 baseline 在每个 mode/stage 的实际权重，在同一权重下重算五组几何界。这样分开声明变化与重新优化两种影响。

采用现有 SLSQP 实现，不宣称全局最优。只对同权重比较施加解析单调性：2L/2H 不减小界，L/2/H0 不增大界，噪声项和点估计完全相同。不得把这种单调性误套到各组局部优化输出。

## 3. 机制域、公式与合法性

机制域是 `[-1,1]^2`，所有真实位置及其凸包位于域内；不声称二次函数在整个欧氏空间具有有限 L。校准球按其与该域的交集解释，代码使用的全球距离是保守外包。

原曲面及其在该域上的解析常数保持不变：

| 曲面 | μ(x,y) | L | H |
|---|---|---|---:|
| linear | .55x + .30y | hypot(.55,.30) | 0 |
| quadratic | .5x + .2y + .06(x²+y²) | hypot(.62,.32) | .12 |
| sinusoidal | .45x + .2y + .08 sin(2x) | hypot(.61,.20) | .32 |

这些梯度与 Hessian 范数的上界在域内可达到，所以 L_half 和非线性 H_zero 确实违反相应的全域声明。真实曲面和这些标签仅用于合成设计与评分；不代表能从现实中的少量效应数据认证 L/H。

设源集合中心和半径为 c_i,r_i，目标为 c_*,r_*，权重 a 属于 simplex，d_ij=||c_i-c_j||+r_i+r_j（对角线取 0）。计算：

```
Bbar(a) = L ||Σ a_i c_i − c_*|| + L(r_* + Σ a_i r_i)
          + H/4 Σ_i,j a_i a_j d_ij²
BLip(a) = L Σ a_i ||c_i − c_*|| + L(r_* + Σ a_i r_i)
R(a) = min(Bbar(a), BLip(a)) + sampling_noise(a).
```

分解保存中心偏移、直接集合半径、中心曲率、集合半径导致的曲率膨胀、BLip 中心距离和噪声。Bbar 的充分条件需要正确 L 和 H；BLip 及拒绝时的外包区间只需要正确 L。因此 H_zero 非线性政策不享有整套声明的统一保证，但某一状态若由合法 BLip 达到最小值，其被采用的数值界仍有合法分支支持。不能把整组每一个输出都标为无效。

记录以下不同概念，不以一个含混的 assumption_valid 代替：声明 L/H 是否满足域上要求；整套声明是否有效；joint-U 覆盖事件是否发生；Bbar/BLip/拒绝外包条件是否满足；实际最小分支是否有合法支持；当前输出与沿路径输出是否合法；方法级统一保证是否适用。

精确相等时，只要合法 BLip 也达到最小值即可支持该界，即使 `active_branch` 的默认标签为 Bbar。保存严格与容差诊断两份；分支数值容差为 1e-12。容差近似相等、有限样本的高覆盖、或观测到全部选择 BLip，都不得把 H_zero 非线性政策升级为已证明的统一保证。

正确/保守整套声明的名义路径失败上界为 eta+zeta=.10；负声明政策记 null。机制覆盖事件是评分事件，不与声明是否合法混为一谈。

## 4. 固定配置与置信预算

继承 `current_method/configs/workflow_full.json`：3 曲面 × 3 几何（supported/bridgeable/unreachable）；每世界 4 个历史来源、每来源 800 人；6 个候选桥；最多 3 个桥，每桥 96 人；199 个校准档案；proxy_scale=.012；eta=zeta=.05。

固定随机顺序为 `default_rng(SeedSequence([seed,surface_id,scenario_id,replicate,20])).permutation(arange(4,10))`。同世界所有方法共享顺序与源观测；不按结果挑选候选，不加入 nearest/targeted/logdet。

R2 为主分析，Rinf 为预先指定次分析。固定预算 0/1/2/3 桥全部报告；主分析 R2、第 3 桥后，新增 288 人。停止阈值半径 .2 和 .3 原样保留。

置信分配不变：R2 的证书乘数为 `sqrt(2 log(2*4/(zeta/2)))`，乘 `||a*s||2`；R2 拒绝外包使用 `sqrt(2 log(2*10/(zeta/2)))` 的坐标噪声界。Rinf 使用 `sqrt(2 log(2*10/zeta))`，证书噪声为其乘 `Σa_i s_i`。这是每个合法政策的有限路径保证，不是所有方法一起的保证，也不保证条件于发布后的覆盖。

## 5. 固定预算、停止输出和纯评分分解

共同完整前缀只采一次。固定预算视图在四个前缀都报告证书。停止视图从相同轨迹重建首次 R≤δ 的时刻并携带已停止结果，不把它当第二次独立实验，也不使用停止后的观测。实际新增成本按停止时实际桥数 ×96 计算。

拒绝输出使用各组自己的 L 所对应的外包区间；不能把拒绝外包称为证书或 sharp region。空交集/不一致不能记作零宽成功。历史 3200 人为沉没成本，校准、元数据和实施成本未计入，必须说明。零发布组的条件发布误差记 NA。

新增纯评分分解（不进入优化/选桥/停止）：

```
signed_causal_error  = Σ a_i true_effect_i − true_target_effect
signed_sampling_error = Σ a_i (observed_effect_i − true_effect_i)
signed_total_error = estimate − true_target_effect
                   = signed_causal_error + signed_sampling_error.
```

保存正负号、绝对因果偏差、其是否被 min(Bbar,BLip) 覆盖以及超界幅度。严格与容差 1e-10 的偏差检查分开。若完整声明正确且 joint-U 事件发生，实际因果偏差必须由几何界覆盖。负声明不一定在当前有限位置和权重上超界；即使几何低估，保守采样项也可能使完整区间仍覆盖。报告不能只看最终覆盖率。

主指标：固定预算完整区间宽度与相对 baseline 的配对差、真值 MAE/MSE/覆盖、因果偏差及几何覆盖、几何/噪声分解。次指标：所有阶段/Rinf、同权重差、首次发布率和实际停止成本、无条件错误发布、路径覆盖、分支/输出有效性、拒绝外包宽度与状态。

保留 9 个格子全表及每几何等曲面权重汇总。按 world 配对，不把组别、预算或阈值当独立重复。完整分析每格 200 世界；配对 bootstrap 在曲面/几何层内重采样，2000 次。各个区间仅为探索性单独区间，不作经多重比较校正的优越性结论。
