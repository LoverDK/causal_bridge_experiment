# 固定设计下的全局分配成本审计

这是原主实验的只读设计计算，没有产生任何新参数、噪声或观测。原协议和主实验结果没有修改。

## 问题与可核验下界

保留原 200 个设计中的先验协方差 P、12 个候选 x_k、观测方差 v_k、目标 t，以及每次观测成本为 1 的设定。半径门槛 0.30 与 alpha=0.05 对应 q_req=0.0045。连续松弛为

    minimize sum_k n_k
    subject to n_k >= 0,
      q(n) = t' (P^-1 + sum_k n_k x_k x_k'/v_k)^-1 t <= 0.0045.

令 A=P^-1+sum n_k x_k x_k'/v_k，N=sum n_k。对任意非零 z，Cauchy–Schwarz 给出

    (t'z)^2 <= (t'A^-1t)(z'Az)
             <= q_req [z'P^-1z + N max_k (x_k'z)^2/v_k].

所以任何可行分配必须满足

    N >= L(z)
      = max(0, [(t'z)^2/q_req - z'P^-1z]
                 / max_k (x_k'z)^2/v_k).

下界不依赖优化器成功，不是把局部优化结果当成全局最优。每个设计同时保存贪心终点和连续分配的 z=A^-1t 证书，采用两者较大下界。连续方案经独立约束检查后给出连续可行上界；逐坐标向上取整并删除可行的冗余观测后，另给整数可行上界。并未声称找到所有设计的精确整数全局最优。

浮点下界另减去 1e-6 * max(1,L) 的安全余量再与 direct 比较。它是可独立重算的数值证书，不是区间算术或 Lean 形式化证明。

## 结果

- 在 198/200 个设计中，保守全局下界已高于 direct 的停止观测数。即使给桥接最优连续分配，也不能在 direct 的预算内满足相同 W 门槛。
- 余下 2 个设计有可行整数桥接分配严格便宜：设计 2 为 55 对 56，设计 62 为 46 对 56。它们也是原贪心便宜的两个设计。
- 上述 198 个设计里，离 direct 最近的是设计 48：保守下界 58.140175，大于 direct 的 56，余量约 2.140175。
- 原贪心成本 / 全局下界的中位数为 1.00435333，最大值为 1.05062760。因此不能主要归咎于单步贪心没有做全局规划。
- 连续可行上界与下界的最大绝对差为 0.000537442，最大相对差为 6.55966e-7。200 个优化中 197 个返回成功；3 个返回 SLSQP 状态 8，保留原状态，其可行方案和独立下界仍有效。

## 范围及审稿意见

结论只针对固定候选、已知矩、固定线性模型、线性矩界 W、相同单位观测成本。它不证明所有统计方法都不可能更便宜，不覆盖真实研究成本异质、新增候选、历史数据已付成本或不同模型。尤其不能由这里推出桥接在任何实际应用中都没有价值。

本审计给 REV-07 的成本比较提供更强的负面边界，也限定 REV-10 的单步选桥与全局分配差距；REV-12 的停止门槛沿用原设置。没有新增覆盖概率实证，未重新验证分布或真实校准，所有审稿问题状态均未更改。其余问题仍保持原未完成范围。

## 文件与运行

- `audit_allocations.py`：独立脚本，仅读取主实验设计与规划。
- `timing3/`：原设计 0–2 的耗时测量，纯计算 0.0555 秒。
- `full200/per_design_bounds.csv`：每设计上下界、原贪心/direct 成本、数值余量、优化状态。
- `full200/allocation_certificates.json`：每设计完整连续/整数分配与可重算的 z、分子、分母。
- `full200/summary.json`：输入哈希、软件版本、脚本哈希、范围与汇总。

运行前估计：由前三个设计实测估计全量 5–15 秒 CPU，无 GPU。实际纯计算 4.0507 秒，含解释器启动约 5.15 秒。
