## 本轮必须核对的理论衔接

1. 当前主要策略使用设计信息确定权重。比较 R2 与 R-infinity 时，明确相同权重、不同策略以及置信预算的区别。不能把看过结果选择的权重代入只对设计型权重有效的界。
2. 一般不确定机制集合下的外包区间，与已知位置 Lipschitz 特例的 sharp region 分开标记。不能以特殊情形的 sharpness 描述一般实现。
3. 当前 targeted workflow 使用最小化预期半径的一步启发式。Theorem 5.6 的 log-determinant greedy 保证属于另外一个明确模型和算法。第一次复现保持实际代码身份，不把启发式重命名为有该定理保证的算法；后续如实现定理版本，另立协议与对照。
4. 模拟中的机制标签、解析平滑性界、已知噪声分布要显式列为本轮条件。模拟运行不能完成真实机制集合有效性验证。

### 已有流程实际覆盖什么

校准联合机制集合 → 按设计优化权重和规划候选顺序 → 读取历史试验结果 → 计算估计与区间 → 半径超过阈值则拒绝 → 采集所选候选的两臂数据 → 更新估计与区间 → 首次发布停止，或耗尽预算后继续拒绝。

规划在读取试验结果前完成。新结果会更新点估计和拒绝区间，但不会改变这组实验的候选顺序、权重或证书半径。半径的变化来自新增来源的设计、几何及样本量。这是设计驱动的序贯采集，不能称为已测试结果驱动的自适应选权。

这里的完整流程不包含所有理论模块的统一验证：机制集合用模拟标签校准，L/H 来自已知函数解析界；几何项取重心界和逐源 Lipschitz 界的较小值；拒绝区间是外包络；targeted 策略是下一轮半径启发式。它不是精确求一般 sharp region，也不是 logdet 定理的桥接算法。其他定理检查保留为独立模块。

## 成本与精度共同评价：作者明确的首轮重点

本节更新首轮评价目标，原算法和旧实验结果保持不变。核心问题是在共同的可靠性要求下，桥接能否以较少成本获得相同精度，或在相同预算下提供更精确的信息。最终结论须说明优势、劣势和取舍出现在哪些场景；不能把通过同一阈值的输出都视为同样精确，也不能把未发布的有效外区间视为没有信息。

### 共同量与可靠性

- 成本 C 记录实际新增参与者；可用预算另记。历史样本、校准、审计和部署成本沿用原定义并注明未计入。不同单次实验成本只在有依据的独立敏感性分析中改变。
- 所有实际返回的有限非空区间 I=[l,u] 都记录半宽 h=(u-l)/2，不论原点估计是否发布。发布区间和拒绝外区间仍保留类型，不称拒绝外区间为sharp区域。拒绝区间未必以原加权估计为中心，所以半宽与原证书半径分别记录；它们不能混用。
- 区间窄表示精度高；是否覆盖真值表示可靠性。共同名义路径保证沿用原90%要求，另报逐预算覆盖、整条路径覆盖、Monte Carlo不确定性和失败计数。不同实际覆盖率不自动视为相同；不以高覆盖独立宣称有效率，也不以窄而失覆盖的区间宣称优势。
- 点估计实际误差与区间半宽分开。原加权估计在未发布时仅可用于标注清楚的诊断；区间中点若用于统一误差诊断，必须注明它可能是另一估计器，不能偷偷改成原论文正式输出。
- 空区间标记为不一致，不可记为零宽或成功；无界区间单独显示，不能删掉之后只平均有限结果。各方法使用相同世界与分母，不只比较各自发布或各自拒绝的不同子样本。

### 两个互补的主比较

1. 给定采集预算，比较精度：0、96、192、288人的预设预算下，展示实际成本、返回区间半宽分布（中心趋势与分位数）及覆盖。主图横轴为实际新增成本、纵轴为区间半宽，按函数和几何分面，并列显示可靠性。不能从两个方法都发布推导出精度相同。
2. 给定精度要求，比较成本：原delta=.2与.3继续作为主要要求；保留原R≤delta的点发布任务，并独立标注“返回区间半宽≤delta”的区间任务。报告首次达标成本与达标概率；未达标记录为预算内未达标，不能删掉后仅比较成功者平均成本。可直接报告预算内达标概率随成本变化，以保留失败世界。

不使用事后选择的成本/宽度加权和来制造单一赢家。若桥接更便宜但区间更宽，报告取舍；只有在成本不高且精度不差、可靠性要求得到支持的范围，才表述为更优。方法差异按世界配对、按预设场景分层估计不确定性；覆盖未达要求的结果仍展示并明确标记。

拒绝外区间与发布区间切换时，实际输出半宽可能跳变，不强制将曲线单调化。若根据区间半宽停止并发布中点，需覆盖所有可能停止时点的共同有效事件，不能以单时点覆盖代替路径保证，也不能据此声称发布条件覆盖。不同方法的实际覆盖差异照实报告，不用评价真值调窄区间来凑相同覆盖。
