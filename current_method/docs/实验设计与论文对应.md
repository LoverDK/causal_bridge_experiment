# 当前实验协议边界

This file records only the current paper protocol boundaries; development-stage history is not shipped.

## 选择与证书

- 设计可测的权重只使用公开表示、设计标准误和冻结配置。
- 结果依赖权重只作为明确标注的无效压力测试；adaptive-R2 不作为有效证书或主要方法结论。
- 在相关源噪声下，R2 对角近似不能仅凭固定权重获得有效覆盖；联合坐标界或完整协方差计算必须使用相应的相关结构。
- 论文报告的是无条件发布事件控制。经验上的 released-only 指标不等同于条件覆盖保证。

## 证据范围

合成实验使用冻结的机制、代理噪声、桥接顺序和随机种子。Many Labs 2 只提供来源留出和标准化干预下的预测参考；它没有真实机制标签。NSW 是同一试验内的局部重建，半合成扩展的真值来自预先指定的响应面。完整 ExAtlas 匹配对照未运行。

## 复现入口

从仓库根目录运行 python reproduce.py current --profile smoke、python reproduce.py workflow --profile smoke 或 python reproduce.py ablations --profile smoke。完整配置和已保存结果分别位于 configs/ 与 results/。
