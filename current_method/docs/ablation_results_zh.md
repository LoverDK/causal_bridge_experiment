# 两组贡献归因实验：结果与可写入论文的结论

完成日期：2026-09-17。结果目录：`results/ablations_full`。

## 结论

两组实验均已完成，并通过原始工作流一致性与独立逐记录核验。

1. **权重优化的作用得到支持**：同一可用来源、同一有效证书、同一桥接顺序下，优化权重在 bridgeable 场景显著提高经验发布率、减少达到发布条件前的实际采集成本。
2. **两种误差界取最小值的额外实用收益未得到支持**：在预先固定的容忍度 0.2、0.3 下，`min(Bbar, BLip)` 与单用 Bbar 的发布率、停止成本完全相同。BLip 偶尔使半径略小，但没有改变发布决策。
3. 因此，新证据支持“适当选权及 barycentric 几何有作用”，不支持“两个界的组合是性能提升的主要原因”，也不支持对未比较方法的总体优越性。

该分析只针对当前 DGP 的贡献归因；ExAtlas 不在本次执行范围内。

## 实验设计

沿用原 workflow_full 的 1,800 个独立模拟世界：三种效应曲面 × 三类几何 × 每格 200 次；机制校准、代理噪声、试验观测和种子完全配对。预算为最多三个桥接试验，每次 96 人；容忍度为 0.2 和 0.3。

为隔离贡献，所有变体共享同一个随机桥接顺序或最近机制桥接顺序。每个来源前缀上，分别在 R2 和 R-infinity 证书下比较优化、均匀、逆方差和最近来源权重；几何消融比较 Bbar、BLip 和两者最小值，并额外在相同权重处评估三个界。所有权重只读取设计信息。

这是审查后在既有 DGP 上增加的配对分析，不是独立新任务上的确认性验证。每一变体首次满足发布条件后停止；另保存统一预算下的反事实评分。统一预算的证书宽度与停止后含拒绝区域的输出宽度分开报告。

## 1. 同一证书下的权重对照

下表为 bridgeable 场景、随机桥接顺序、最大预算 288 人；每行汇总 600 个配对世界。成本是实际采集人数的均值。

| 证书 | 容忍度 | 权重 | 发布率 | 实际人数 |
|---|---:|---|---:|---:|
| R2 | 0.2 | 优化 | 38.50% | 261.44 |
| R2 | 0.2 | 均匀 | 1.33% | 288.00 |
| R2 | 0.2 | 逆方差 | 0.00% | 288.00 |
| R2 | 0.2 | 最近来源 | 0.00% | 288.00 |
| R2 | 0.3 | 优化 | 100.00% | 159.68 |
| R2 | 0.3 | 均匀 | 20.33% | 283.52 |
| R2 | 0.3 | 逆方差 | 0.00% | 288.00 |
| R2 | 0.3 | 最近来源 | 0.00% | 288.00 |
| R-infinity | 0.2 | 四种权重 | 均为 0.00% | 均为 288.00 |
| R-infinity | 0.3 | 优化 | 31.83% | 244.96 |
| R-infinity | 0.3 | 均匀／逆方差／最近来源 | 均为 0.00% | 均为 288.00 |

R2、容忍度 0.3 下，优化对均匀权重的发布率增益为 **79.67 个百分点**，配对 bootstrap 95% 区间 **[77.00, 82.33]**；节省 **123.84 人**，区间 **[119.36, 128.32]**。容忍度 0.2 下，发布率增益为 **37.17 个百分点**，区间 **[34.50, 39.83]**。

这不是只靠提前停止改变样本量的现象。在共同采完三个试验的固定预算下，R2 的 all-target MAE / 证书全宽为：

| 权重 | MAE | 证书全宽 |
|---|---:|---:|
| 优化 | 0.0334 | 0.4224 |
| 均匀 | 0.1405 | 0.7061 |
| 逆方差 | 0.3617 | 1.1097 |
| 最近来源 | 0.1307 | 1.0208 |

逆方差偏重精度较高但离目标较远的初始来源，在这一构造中表现较差；这不是对逆方差在任意可运输模型中的否定。所有初始来源的噪声尺度相同，所以在零桥接阶段均匀与逆方差权重相同；加入样本量较小的桥接来源后两者才不同。

最近机制顺序的结果也全部保留：bridgeable、R2、容忍度 0.3 下，优化发布率为 100%，均值成本 241.60 人，其他三种权重均不能发布。容忍度 0.2 下各方法均失败。该顺序固定，结果不能解释为优化权重重新选择了更好的桥接位置。

### 反例与适用边界

- supported 场景的 R2 下，优化、均匀和逆方差都能在零新增人数时 100% 发布。此时均匀／逆方差 MAE 约 0.0149，优化约 0.0153；优化不保证点误差普遍更小。
- unreachable 场景全部变体均不发布并耗尽预算。
- 严格容忍度下 R-infinity 的保守性依旧明显，不能因为本次补出权重优势就宣称该问题已经解决。
- 不同证书的随机项和预算分配不同；主要归因来自同一证书内部比较。

## 2. 几何误差界消融

在完全相同的桥接来源前缀上，分别重新优化三个几何目标，并在相同的优化最小值权重处评估三个界。

| 对照 | 正式运行结果 | 可支持结论 |
|---|---|---|
| min(Bbar, BLip) 对 Bbar | 所有已报告场景、顺序、证书、容忍度的发布率与成本一致 | 本 DGP 下，最小值组合没有额外发布／成本收益 |
| min 对 BLip | bridgeable/random/R2/0.3：100% 对 0% 发布；159.68 对 288 人 | barycentric 几何在这组支持结构中实质重要 |
| 三个界在同一权重处评估 | 非线性曲面中 BLip 偶尔更紧；主要发生在 unreachable 场景 | 微小半径收紧不一定产生可用的发布收益 |

在最终固定预算的汇总比较中，min 对 Bbar 的平均全宽改进最大约 0.0036；其 MAE 也不总更低。不能把“取最小值必然不大于单个界”的代数事实当作新的经验性能发现。

## 核验和统计口径

- 全部 **28 项单元测试**通过，其中新增六项检查匹配原工作流、逆方差定义、单来源恒等式、优化失败回退、信息隔离和共享来源前缀。
- 正式结果通过 **15 项**结构和校准检查。
- 独立重算全部 **172,800 个计划**：最大半径误差 `2.22e-16`，预测误差为 0。
- 独立重建全部 **345,600 条停止记录**：最大误差 `5.11e-15`，实际成本一致。
- 与原 workflow_full 的 random R2 / nearest R2 逐条一致，各 **14,400 条记录**。
- 本实验各单元格观察到的路径覆盖率均为 100%，错误发布为 0；这表明本模拟下证书很保守，不能宣称普遍 100% 覆盖或条件覆盖保证。
- Bootstrap 以世界为单位配对并在曲面内分层，2,000 次重采样；区间为探索性单项 95% 区间，不是同时显著性声明。

完整结果文件保留所有 supported/bridgeable/unreachable 场景、两种顺序、两种证书、两种容忍度与所有预算。零发布时的条件 MAE 为缺失值。

## 使用与论文对应

运行：`python run_ablations.py --profile full --workers 4`。入口拒绝覆盖已存在的结果目录；复跑时请使用独立源码副本。可单独执行 `python audit_ablations.py` 重建核验。

结果以一张权重表和一张几何消融表进入论文附录；正文仅作短指引。独立数值结果、固定预算评分和审计记录均保留在 `results/ablations_full/`。

这两组实验补上了内部贡献归因，但没有解决完整 ExAtlas 对照、真实机制集合校准、理想全局优化器与局部实现的区别，也没有修复冻结理论中的两个待核条件。
