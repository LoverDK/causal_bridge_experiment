# 完整流程正式结果：可用于论文的结论与边界

结果来自 `results/workflow_full`，配置、源文件与产物哈希均已校验。正式运行 1,800 个独立世界，产生 86,400 条世界×方法×容忍度×预算记录。32,883 条采集日志是各方法、各阈值的配对策略日志，并非 32,883 个独立研究。

## 最有信息量的对照

在 bridgeable 场景，每个汇总由三类函数各 200 个独立世界等权组成，共 600 个。最大新增预算 288 人，历史档案视为已存在。

无桥接的 archive-only R2 在该场景两种阈值下都不发布，新增成本为零；这说明桥接确实改变了结论，但不能因此省略直接目标试验的优势。

- δ=.3 时，targeted R2 相比 random R2 在相同 100% 发布率下平均少 41.76 人，降幅 26.15%。世界配对、按函数分层 bootstrap 的 95% 区间为少 [37.44,46.24] 人。
- δ=.2 时，相比 random R2，targeted R2 发布率提高 28.00 个百分点，95% 区间 [25.50,30.50] 个百分点；平均少 34.40 人，95% 区间为少 [30.72,37.92] 人。
- 直接目标试验是重要反例：δ=.3 时与 targeted R2 同样全发布，但平均少 21.92 人，95% 区间 [19.84,24.00]；δ=.2 时花 288 人可全发布，而 targeted R2 仍拒绝 33.50% 的世界。不能宣称档案桥接整体优于直接试验。

这些是模拟中的策略比较，区间是探索性逐项区间，不是经多重比较调整的全家族显著性结论。所有策略都满足共同声明的至少 90% 路径覆盖目标，但实际覆盖率并非被强行调到完全相等；不能据此宣称严格的等实际覆盖最优性。

## 何时档案有用、何时候选菜单无用

supported 场景下，五种档案方法在两个阈值均无需新采集即可发布。直接目标试验分别需要 288 人（δ=.2）或 96 人（δ=.3）。这是历史证据已经具有支持时的直接价值，不是桥接策略本身的优势。

unreachable 场景下，所有采集桥接的方法都耗尽 288 人仍拒绝，archive-only 同样拒绝但不花新预算。直接目标试验则分别以 288 或 96 人完成发布。这暴露出当前逐步桥接策略缺少可证明的无效菜单提前停止和直接目标试验切换；本轮保留了这项负面结果，没有事后加停止规则改善成绩。

## 覆盖和计算可信度

联合机制集合经验覆盖率为 94.8889%，声明目标为 95%。在各函数×场景×策略×容忍度的 200 世界单元中，完整输出路径经验覆盖最小值为 97.5%。档案策略本轮没有观察到错误发布，不意味着真实错误概率为零；逐单元 Wilson 区间保存在 workflow_summary.csv。直接目标试验的错误发布和路径漏覆盖也如实保留。

7 项新增流程测试、21 项正式结果验收通过；全目录 22 项测试通过。正式采集日志重新构造了每次估计，检查停止后无新增观测，重新计算了保存权重的证书值。21 项验收中统计部分使用全家族 .01 的单侧检验；未检出失准不等于证明所有科学假设。

半径用了球集合的重心/曲率上界，并与逐源 Lipschitz 误差界取较小值。后者是额外的有效收紧，未声称它就是论文 sup G。求解器给出可行解；实际路径零起点失败也不能证明全局最优。目标与候选机制真值从未输入规划器，模型参数 L/H 来自模拟解析界。

## 可写进论文的中心句

“在二维、联合校准的有限预算合成流程中，按证书半径选择桥接实验能够相对于随机及最近机制策略提高发布效率，但优势依赖已有档案与候选菜单的支持结构；在直接目标试验可行且每人成本相同的部分场景，直接实验仍更有效。实验同时显示了选择安全证书的保守代价以及支持不足时正确拒绝与预算浪费的区别。”

这不是已完成真实研究档案机制校准的证据。不能写成普遍节省实验成本、普遍优于 R2、一般自适应政策保证或 ICLR 接收的充分条件。
