# 指标与符号：给第一次阅读新版的人

| 项目 | 意义 | 看结果时的注意点 |
|---|---|---|
| U_i、U_* | 源研究/目标可能的机制集合 | 不是“估计效应的置信区间”；集合包含的是机制坐标 |
| joint_set_coverage | 一整个档案中所有源和目标真实机制都在集合里的频率 | 新版需要联合事件，逐点 95% 不够 |
| eta | 集合校准失败的预算 | 本套件 .05；Gaussian proxy 的历史审计只在模拟中获得机制真值 |
| zeta | 同时源噪声事件失败的预算 | 本套件 .05；组合主保证至少 1-eta-zeta=.90，不要统一误标成 95% |
| robust_Rinf | 精确盒顶点半径 + simultaneous sub-Gaussian noise | 允许效应结果依赖的 simplex 权重；通常保守 |
| design_R2 | 同一组不依赖效应结果的权重下、更窄的平方和噪声项 | 不是任意选权都能用 |
| adaptive_R2_invalid | 把 R2 用于看过结果的权重 | 故意违反前提的消融，不能发表为有效方法 |
| coverage | 对模拟中真实目标效应的纳入率 | 必须和 width/release 看；高覆盖不能反过来证明集合假设 |
| mean_width | 两侧区间的总宽度 | 很宽的区间可能几乎总覆盖，未必实用 |
| release_rate | 半径不超过预先科学容忍度的比例 | 不使用目标结果调阈值；0 发布不等于误差为 0 |
| released_mae | 仅已发布目标中的 MAE | 不同方法可能选不同目标，是不同选择策略的风险 |
| unconditional_bad_release | 所有测试档案中，既发布又误差超过容忍度的比例 | 主定理推出的控制对象之一；不同于 conditional_bad_release |
| sharp PI | 指定模型类中所有可行目标值的精确范围 | 本套件 LP 只对已知有限位置、L-Lipschitz 类 sharp |
| outer interval | 包含可行目标集的保守外包络 | 集合不确定的通用模型不冒称 sharp |
| information_ratio | log-det 值 / 穷举最优 log-det 值 | 分母也是 log-det 目标 |
| target_radius_ratio | 当前目标 posterior 半径 / 目标导向穷举最小半径 | 接近 1 越好；与 information_ratio 不是一回事 |
| reference_inclusion | 真实数据中带噪 held-out 来源估计落入预测区间的频率 | 不能换称真实因果效应 coverage |
| MC SE / Wilson | Monte Carlo 抽样误差 / 二项区间 | 不把共享训练数据的 Many Labs folds 当独立二项样本 |

## 结果文件怎么找

- 想看每个档案如何决策：operational_records.csv + operational_audits.csv。
- 想看发布/拒绝权衡：operational_frontier.csv；threshold 一列对应预先固定 tolerance。
- 想看 sharp 区间是否真可行：pi_witnesses.json 逐条保留下端点与上端点的源/目标赋值。
- 想看桥接有没有偷换目标：bridge_records.csv 的 information_ratio 与 target_radius_ratio。
- 想看真实结果有没有泄漏：manylabs_holdouts.csv 的 source_ids 以及 manylabs_leakage_tests.csv。
- 想确认是否可复现：run_manifest.json + data/provenance.json + configs/full.json。
