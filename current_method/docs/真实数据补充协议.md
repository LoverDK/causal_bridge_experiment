# Many Labs 2 跨国家留出补充协议

2026-09-16 固定本补充分析；原始 framing 数据已在先前实验中使用，因此这是事后补充分析，不是预注册验证。代码运行前确定以下对照，不根据结果调整。

问题：来源留一的低误差是否依赖同一国家的其他来源仍留在训练集中？比较来源留一（LOSO）与整国留出（LOCO），后者剔除目标国家的所有来源，逐目标来源评分。

沿用固定 commit 和 SHA256 的 7,228 个真实参与者、57 个来源。国家标签来自原始 Country 列，每个来源要求唯一国家。所有目标响应仅用于最后评分；对整个留出组翻转 Yes/No 后，重新汇总并重拟合，预测与发布决策必须不变。目标两臂样本量是允许使用的设计信息。

五种点估计：逆方差固定效应、DerSimonian--Laird 随机效应、来源等权平均、来源中位数、两端各删 floor(0.1K) 个来源的截尾平均。仅前两种输出原有模型下的 95% noisy-reference 预测区间。所有方法共享训练来源。额外报告去掉单个训练来源后重拟合所致预测最大变化，用于影响度诊断。

LOSO 与 LOCO 均报告来源等权 MAE、国家内先平均再国家等权的 MAE、最大误差。前两种方法报告 noisy-reference inclusion、宽度与半径阈值 .10/.15/.20/.25/.30 下的发布率、已发布 MAE 和包含率。为了区分样本量损失与国家支持损失，固定效应另做 100 次 outcome-independent 的训练来源下采样：对每个目标从 LOSO 的其余 56 来源抽出与该目标 LOCO 相同数量的来源，用固定种子 2026091607；报告平均误差，不视为额外独立目标或给出虚假的独立重复标准误。

明确边界：同一 framing 干预；公开便利样本；来源间可能有关联；LOCO 不建立跨干预的 U_i、L、H 或因果真值。覆盖指标只针对有噪声的留出来源效应估计；没有真实桥接干预采集。本分析的作用是检查基准的依赖结构及对照强度，不能替代完整真实机制校准。
